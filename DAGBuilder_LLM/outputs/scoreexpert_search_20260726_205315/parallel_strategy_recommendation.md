# 32 卡场景并行策略推荐

## 输入场景

- 总卡数：32
- 拓扑：2 个亲和组，每组 1 台机器，每台 16 卡
- 模型：32 层，隐藏维度 4096，FFN 隐藏维度 11008
- 全局 Batch Size：128
- TP 上限：16
- 仿真器：`simulator_v2`
- 本轮模式：ScoreExpert 初始化候选评估，不包含 LLM 演化轮次

## 推荐策略

| 参数 | 推荐值 |
| --- | ---: |
| PP | 2 |
| TP | 16 |
| DP | 1 |
| MBN | 64 |
| 单个 Microbatch Size | 2 |
| 活跃卡数 | 32 |
| 闲置卡数 | 0 |
| simulator_v2 最长路径 | 1.789702814 s |

部署解释：

- 两个 PP stage 分别使用一台 16 卡机器；
- 每个 stage 内建立一个 TP=16 通信域；
- DP=1，不建立跨副本的数据并行通信；
- 32 层平均分为两个 stage，每个 stage 负责 16 层；
- MBN=64 用于降低 PP=2 的流水线气泡。

## 验证结果

- 完整搜索空间：322 个并行组合
- ScoreExpert 初始化阶段送入 Evaluation：142 个候选
- 通过硬规则、RuleCheck 和 simulator_v2：51 个候选
- 其余 91 个候选因 `memory_hard_overflow` 被拒绝
- 推荐策略 RuleCheck：0 错误、0 警告
- 推荐策略 DAG：4230 个节点、10374 条边，仿真前后拓扑不变

当前结论是本轮 142 个被提名并实际评估的候选中的最优结果，不等价于对全部
322 个组合逐一执行 Evaluation 后证明的全局最优。
